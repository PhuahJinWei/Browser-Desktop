# 3. Model weights in four tiers

Status: accepted (M0) · the on-demand tier is **removed** by [ADR 15](./0015-no-on-demand-models.md),
and the bundled tier now means what it always said: one model, **in the repository**, served from
this origin. Weights are fetched and digest-checked at build time by `tools/sync-model.mjs`
instead of at runtime, so the consent dialog and the download manager described below are gone —
there is nothing left to consent to or to download.

### A note on repository size and shape

Vendoring costs 23 MB in git, of which 22 MB is one `.onnx` file that git correctly treats as
binary. The awkward one is `tokenizer.json`: a 30,000-token vocabulary pretty-printed as JSON,
which git counts as 30,685 lines of text. Unmarked, it made GitHub read the repository as 52% JSON
against 35% TypeScript, and put tens of thousands of unreviewed lines into any diff that touched
the model.

`.gitattributes` marks `public/models/**` as `linguist-vendored` and `-diff`, which keeps it out
of the language statistics and collapses it in diffs. Neither changes what is served or how it is
checked — integrity comes from the digests in `models.json`, enforced by `tools/sync-model.mjs`,
not from reading the diff.

## Context

Models are the payload. Bundling everything makes the first visit enormous and burns the Pages
bandwidth allowance; bundling nothing means a visitor stares at a progress bar before seeing
anything work. The privacy claim also has to survive contact with a CDN.

## Decision

| Tier        | Source                              | Rule                                                                         |
| ----------- | ----------------------------------- | ---------------------------------------------------------------------------- |
| 0 Bundled   | in-repo, same origin                | total <= 80 MB; no consent needed; works offline immediately                 |
| 1 On-demand | huggingface.co                      | explicit consent showing size, licence and host; resumable; SHA-256 verified |
| 2 Built-in  | Chrome Prompt/Summarizer/Translator | zero download by us; optional features only                                  |
| 3 Sideload  | user supplies files                 | fully air-gapped                                                             |

Tier 0 currently holds all-MiniLM-L6-v2 int8 (22.6 MB, from M1) and Whisper tiny int8 (41.6 MB,
from M2): 64.2 MB of the 80 MB budget, or roughly 1,595 first-time visitors per month within the
100 GB soft limit. Photo models (MobileCLIP-S0 at 52 MB, CLIP ViT-B/32 at 146 MB) are Tier 1.

`models.json` is generated by `tools/fetch-model-registry.mjs` from the Hugging Face API, so sizes
and digests are exact rather than transcribed.

## Consequences

- Every downloaded file is checked against a pinned SHA-256 before use, which also pins the model
  revision and defends against a CDN serving something else.
- The 30-second demo never waits on a download.
- Adding a model means editing a spec and rerunning a script, not hand-editing JSON.
- Licences are carried in the registry: MobileCLIP is Apple ASCL, and RMBG-1.4 (a later candidate)
  is non-commercial. These must be checked before any commercial use.
